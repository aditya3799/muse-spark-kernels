### Mechanism

v97 preserves v87 RED=5's:

- round-robin owner rule `j % S`;
- receive-slot addressing;
- rank 0 -> rank 1 -> rank 2 FP32 addition order;
- `stmatrix` output transform;
- BF16 rounding and vector output stores;
- 64-row output tile, 36 clusters, cluster size 3, and eight-stage mainloop.

Only the remote partial-sum transport changes. Each thread stages a remote
fragment in the idle TMA ring at:

```cpp
dst   = j % S;
local = (j / S) * 128 + tid;
packet[dst * OWN + local] = accumulator_fragment;
```

After `fence.proxy.async.shared::cta` and a 128-thread barrier, thread 0 issues
one `cp.async.bulk.shared::cluster.shared::cta` transfer to each peer. Thus
each CTA performs two bulk transfers instead of approximately 1,280-1,408
